# Signals

Kurzlebige, verifizierte Entwicklungen für die Content- und Conversation-Arbeit
aller Plattformen.

## Zweck

Ein Signal ist eine neue Studie, ein Produkt- oder Plattform-Update, eine Akquisition,
eine regulatorische Entwicklung oder eine relevante Marktbewegung in AI, Health,
Computer Vision, Wearables, Longevity oder Founder/Product. Es ist **kein**
Evidenzbeleg für klinische Wirksamkeit, Diagnose oder Kausalität.

## Ablauf

1. `x-knowledge` und `health-signals-monitor` prüfen die Primärquelle und, wenn nötig,
   eine unabhängige Einordnung.
2. Ein Bericht pro Run liegt unter `YYYY-MM-DD-HHMM.md`.
3. Nur langlebige Evidenz oder Validierung wandert zusätzlich als Einzeldatei nach
   `knowledge/`; ein zeitgebundenes Signal bleibt hier.
4. Plattform-Jobs dürfen frische Signale als Anlass nutzen, nie ohne Kontext,
   Quellenprüfung und menschliche Freigabe.

## Grenzen

- Je Bericht maximal drei Ereignisse, nach zugrunde liegendem Ereignis dedupliziert.
- Nur die letzten 30 Tage. Die Twitter-Cleanup-Routine entfernt datierte Berichte.
- Keine Meldung bei reinen Gerüchten, Marketing-Claims ohne prüfbare Primärquelle,
  Funding ohne strategische Relevanz oder generischem Branchenrauschen.
- Hauptposts bleiben linkfrei; ein Quellenlink gehört erst nach Freigabe in eine eigene
  Antwort oder die plattformspezifische Quellenangabe.
